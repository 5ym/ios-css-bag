# ios-css-bag

iOS Safari をクラッシュさせる CSS の PoC。

`filter: drop-shadow()` を巨大な要素に対して連続アニメーションで適用し続けることで、
WebKit のレンダリングを過負荷にしてタブ(場合によってはブラウザごと)を落とす。

## ⚠️ 注意

- **開くと iOS Safari がクラッシュ・フリーズします。** 保存していないタブがある状態で開かないでください。
- 挙動は iOS / WebKit のバージョンに依存します。対策済みのバージョンでは落ちないことがあります。
- 教育・検証目的の PoC です。他人の端末で無断で実行するなどの迷惑行為には使わないでください。

## 中身

`index.html` 一枚のみ。回転する黒い矩形に強い `drop-shadow` をかけているだけ。
